# Jejak

Progressive Web App untuk refleksi & pengambilan keputusan berbasis metakognisi.

100% lokal di device — tanpa server, tanpa akun/login, tanpa API call ke AI apa pun. Semua data tersimpan di `localStorage` browser.

## Tech Stack

- React + TypeScript + Vite
- PWA via `vite-plugin-pwa`

## Development

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
```

## Deploy

Project ini siap di-deploy via git-based deploy ke Netlify (`netlify.toml` sudah disiapkan) atau Vercel (auto-detect Vite).
